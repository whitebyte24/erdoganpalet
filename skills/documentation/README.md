# 📚 Documentation Skill (Dokümantasyon Yeteneği)

## 📌 Amaç
Yazılım projeleri, API'ler, mimari kararlar ve kullanıcı süreçleri için eksiksiz, anlaşılır ve güncel dokümantasyon üretmek.

## 🛠 Kapsam ve Görevler
1. **Teknik Doküman:** Mimari şemalar, API referansları, sınıf/fonksiyon açıklamaları.
2. **Kurulum Rehberi:** Projeyi yerel ve canlı ortamda ayağa kaldırmak için adım adım talimatlar.
3. **Kullanıcı Rehberi:** Nihai kullanıcılar için ekran görüntüleri ve açıklamalar içeren kılavuzlar.
4. **Değişiklik Kayıtları (Changelog):** Sürüm notları (Release Notes) ve breaking change duyuruları.

## 📋 Best Practices
- Dokümanlar kodla birlikte güncellenmeli ve yaşayan belge (living documentation) olarak tutulmalıdır.
- Karmaşık süreçler Mermaid diyagramları ile görselleştirilmelidir.
