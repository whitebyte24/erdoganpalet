# 🔍 SEO Skill (Arama Motoru Optimizasyonu Yeteneği)

## 📌 Amaç
Web uygulamalarının ve içeriklerin arama motorlarında görünürlüğünü en üst düzeye çıkarmak; teknik, yapısal ve içerik odaklı SEO optimizasyonlarını gerçekleştirmek.

## 🛠 Kapsam ve Görevler
1. **Teknik SEO:** Meta başlıklar, açıklamalar, hiyerarşik etiket yapısı (`h1`, `h2`), canonical URL tanımları.
2. **İç SEO (On-Page):** Anahtar kelime yoğunluğu, semantik HTML kullanımı, iç linkleme (internal linking).
3. **Yapısal Veri (Structured Data):** JSON-LD şemaları (Organization, Article, Product, Breadcrumb, FAQ).
4. **Site Haritası & Robots:** Otomatik `sitemap.xml` ve `robots.txt` üretimi ve doğrulaması.
5. **Performans & Core Web Vitals:** LCP, CLS, INP metriklerini optimize etme, görsel sıkıştırma, lazy loading.

## 📋 Best Practices
- Her sayfada tek bir `<h1>` başlığı bulunmalıdır.
- Görsellerde açıklayıcı `alt` öznitelikleri zorunludur.
- Tüm dinamik sayfalar için Open Graph (`og:image`, `og:title`) meta etiketleri eklenmelidir.
