# 💼 Business Skill (İş Geliştirme Yeteneği)

## 📌 Amaç
Stratejik kararlar almak, ticari teklifler hazırlamak, maliyet/gelir modelleri oluşturmak ve rakip analizi ile iş süreçlerini büyütmek.

## 🛠 Kapsam ve Görevler
1. **Teklif Hazırlama:** Müşteri ve ortaklar için detaylı proje teklif dosyaları (RFP/RFQ) oluşturma.
2. **Maliyet Analizi:** Sunucu, altyapı, lisans ve iş gücü kalemlerini hesaplayarak ROI (Yatırım Getirisi) çıkarma.
3. **Rakip Analizi:** Pazardaki rakiplerin SWOT (Güçlü, Zayıf yönler, Fırsatlar, Tehditler) analizini yapma.
4. **Müşteri İletişimi:** Profesyonel e-posta, toplantı notları ve durum güncellemeleri yazma.
5. **İş Planı:** Lean Canvas veya geleneksel iş modeli tuvali (Business Model Canvas) oluşturma.

## 📋 Best Practices
- Tekliflerde zaman, bütçe ve kapsam (Scope) kesin sınırlarla belirtilmelidir.
- Maliyet analizlerinde gizli veya değişken maliyetler (ör. cloud bandwidth, API kullanım kotaları) hesaba katılmalıdır.
