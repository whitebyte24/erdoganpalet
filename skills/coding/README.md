# 💻 Coding Skill (Yazılım Geliştirme Yeteneği)

## 📌 Amaç
Canlı ortama (production-ready) hazır, yüksek kaliteli, güvenli, sürdürülebilir ve test edilebilir yazılım geliştirmek.

## 🛠 Kapsam ve Görevler
1. **Mimari Tasarım:** Modüler, ölçeklenebilir ve bağımlılıkları düzenli yazılım mimarisi kurgulama.
2. **Kod Üretimi:** Strict TypeScript, temiz kod (Clean Code) ve SOLID prensiplerine uygun geliştirme.
3. **Refactoring:** Spagetti veya eskimiş kod bloklarını okunabilir ve modüler yapılara dönüştürme.
4. **Test:** Unit test, entegrasyon testleri ve uçtan uca (E2E) test stratejileri.
5. **Performans Optimizasyonu:** Memory leak önleme, lazy loading, caching ve sorgu optimizasyonu.

## 📋 Best Practices
- Her işlev (function) tek bir sorumluluğa sahip olmalıdır (Single Responsibility Principle).
- Tip güvenliği (TypeScript `any` kullanımından kaçınma) kesin kuraldır.
- Asenkron işlemler doğru `try/catch` ve hata yönetimleri ile sarmalanmalıdır.
