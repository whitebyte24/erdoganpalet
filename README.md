# ERDOĞAN PALET A.Ş. — Kurumsal Web Sitesi & Dijital Ürün Kataloğu

Bu proje, Türkiye'nin lider ahşap palet üreticilerinden **ERDOĞAN PALET** için sıfırdan geliştirilmiş, yüksek performanslı, dönüşüm odaklı ve modern kurumsal Next.js 15 web uygulamasıdır.

---

## 🛠️ Kullanılan Teknolojiler

- **Core Framework**: Next.js 15 (App Router, Server Components & SSG)
- **Dil**: TypeScript (%100 Tip Güvenliği)
- **Stil & Tasarım Dili**: Tailwind CSS v4 + Özel Tasarım Sistemi (Apple/Linear/Stripe Seviyesi Modern Görsel Doku)
- **Animasyon & İnteraktivite**: Framer Motion
- **İkon Seti**: Lucide Icons
- **SEO & Yapısal Veri**: JSON-LD, Open Graph, Twitter Cards, Sitemap.xml, Robots.txt

## 📄 Oluşturulan Sayfalar

1. **Anasayfa (`/`)**:
   - Etkileyici Hero alanı, EPAL & ISPM-15 rozetleri
   - Canlı İstatistikler (5.000+ Sipariş, 20+ Yıl, 100+ Müşteri, 81 İl)
   - 6 Ana Ürün Kategorisi
   - 6 Kurumsal Avantaj Kartı (WhyUs)
   - 6 Adımlı Üretim ve Kalite Süreci
   - Galeri Önizlemesi & Müşteri Yorumları
   - 11 Detaylı Türkçe SSS (Sıkça Sorulan Sorular)
   - Yüksek Dönüşümlü Teklif Çatısı

2. **Ürünler (`/urunler`)**:
   - Anlık arama (isim ve ölçü bazlı)
   - Kategori filtreleme tabları
   - Detaylı ürün kartları (statik/dinamik yük kapasiteleri, sertifikalar)

3. **Ürün Detay (`/urunler/[slug]`)**:
   - Teknik çizim maketleri ve özellikleri
   - Taşıma kapasitesi matrisi (statik, dinamik, raf)
   - Sektörel kullanım alanları ve teknik avantajlar
   - Doğrudan ürün bazlı teklif alma butonu
   - Benzer ürün önerileri

4. **Hakkımızda (`/hakkimizda`)**:
   - 20 yılı aşkın şirket hikayesi
   - Misyon ve vizyon bildirgesi
   - 10.000 m² kapalı alan üretim tesis detayları
   - Kalite politikası ve FSC sürdürülebilirlik ilkeleri

5. **Galeri (`/galeri`)**:
   - Üretim tesisi, depolama, ürünler ve sevkiyat kategorili filtreleme
   - İnteraktif Modal Lightbox detay inceleme

6. **İletişim (`/iletisim`)**:
   - İletişim formu
   - Fabrika adresi, çalışma saatleri, telefon, e-posta, WhatsApp hattı
   - İnteraktif harita alanı

7. **Teklif Talebi (`/teklif-al`)**:
   - Ad soyad, firma adı, telefon, e-posta, ürün türü, ölçüler, adet, ISPM-15 checkbox ve özel mesaj alanlı interaktif form
   - Anlık özet raporu ve onay ekranı

## 🚀 Çalıştırma ve Kurulum Talimatları

### Geliştirici Sunucusunu Başlatma (Local Dev Server)

```bash
npm run dev
```

Tarayıcınızda `http://localhost:3000` adresini açarak inceleyebilirsiniz.

### Production Derlemesi Yapma (Production Build)

```bash
npm run build
npm run start
```
